# 介面（UI）

給開發者與 AI 讀的說明：`index.html` 的介面結構、視覺規則，以及修改時要遵守的事。

## 視覺 token（`:root`）
| 變數 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0b111b` | 背景（深色夜景） |
| `--panel` | `rgba(13,18,24,.76)` | 面板底色，搭配 `backdrop-filter: blur(14px)`、圓角 14px |
| `--line` | `rgba(255,255,255,.09)` | 細邊線 |
| `--text` / `--muted` | `#EDF2F5` / `#8B99A5` | 主文字／次要文字 |
| `--cyan` | `#5ED3EF` | 強調色（標題、選取） |
| `--up` / `--down` / `--flat` | `#ff4d4f` / `#22b35e` / `#aab4bd` | **紅漲、綠跌**、持平 |
| `--sans` / `--mono` | Outfit＋系統中文字型／JetBrains Mono | 內文／數字 |

數字一律用等寬字型，並用 `tone(值)` 取得 `up｜down｜flat` class。

## 版面（桌面）
```
┌──────────────────────────────────────────┐
│ 標題（左上）                  排行榜（右上）│
│                                            │
│            3D 場景（全螢幕）                │
│                                            │
│ 資訊卡（左下，可收合）      時間／速度（右下）│
└──────────────────────────────────────────┘
```
| 元件 | id | 內容 |
|---|---|---|
| 標題 | `#brand` | 副標與主標 |
| 排行榜 | `#board` | 上一家／下一家、頁碼、特殊入口按鈕、依成交金額排序的列表 |
| 資訊卡 | `#card` | 名稱、收盤價、近 30 日成交金額圖、成交金額、成交量、開高低、三大法人 |
| 時間與速度 | `#player` | 時鐘、−1h／+1h、白天／夜晚切換、速度（暫停、1×、10×、30×、60×）、快門、日夜循環 |
| 載入畫面 | `#loading` | 載入完成後淡出，並設 `window.__ready = true` |

## 手機版（寬度 ≤ 760px）
- 排行榜面板縮成**單列橫幅**：小標題、← 頁碼 →、入口按鈕排成一列，高度約 36px，不把其他面板往下推。
- 時間面板緊接在橫幅下面；說明文字、快門列、日夜循環隱藏。
- 資訊卡預設收合成一行（名稱＋收盤價），點右上角箭頭展開。
- 寬度 ≤ 370px 時省略頁碼，避免碰到標題。
- 預設播放速度：手機 10×、桌面 1×。
- 觸控：單指旋轉、雙指平移與縮放。

## 鍵盤與滑鼠
← → 換一家、空白鍵暫停、1–4 速度、− = 調時間、E 快門、N 日夜循環、C 重設視角、P 前往特殊區域；左鍵旋轉、中鍵（或右鍵）平移、滾輪縮放。

## 場景內的資訊招牌
每間店的街角有一支**灰色立式電子招牌**（`addPylon`／`pylonTexture`）：名稱、市值、收盤價。
- 所有招牌共用同一組幾何與材質，每間店只換一張貼圖。
- 機身灰色；價格依漲跌用 `--up`／`--down` 顏色。
- 沒有資料的欄位顯示「—」，版面不變動。

## 規則（請 AI 遵守）
1. **紅漲綠跌**，顏色只用上面的 token，不另外加色。
2. 畫面一定要標註資料來源、資料日期，以及「僅供參考，不構成投資建議」。
3. 招牌、標誌**只放文字，不放公司 logo**。
4. 所有按鈕要有 `aria-label`／`aria-pressed`、`:focus-visible` 外框；尊重 `prefers-reduced-motion`。
5. 新面板要同時處理桌面與手機（≤ 760px）版面，且不能讓既有面板被推開或重疊。
6. 修改 `index.html` 前，先用 `// ==== [` 搜尋區塊標記，只讀需要的區塊。

## 提示詞範本
> 請閱讀 `docs/ui.md` 與 `index.html` 的 `// ==== [介面]` 區塊。新增一個面板／按鈕 `〔名稱〕`：〔功能描述〕。遵守 `:root` 的顏色 token，桌面與手機（≤ 760px）版面都要處理，手機版不能增加現有面板的高度。輸出：HTML、CSS，以及綁定事件的 JS，並說明手機版怎麼排。
